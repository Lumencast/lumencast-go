# Code of Conduct

This project adopts the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating, you agree to uphold this code.

## Reporting

Report unacceptable behaviour to the maintainers listed in
[`.github/CODEOWNERS`](.github/CODEOWNERS). Reports are handled confidentially.

For protocol-wide governance issues spanning multiple SDKs, the
`lumencast-protocol` repo's
[CODE_OF_CONDUCT.md](https://github.com/Lumencast/lumencast-protocol/blob/main/CODE_OF_CONDUCT.md)
takes precedence.
